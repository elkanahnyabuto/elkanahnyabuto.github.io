# Elkanah Nyabuto

Static academic website for GitHub Pages.

## Publish on GitHub Pages

1. Upload all files and the `assets` folder to the `main` branch of `elkanahnyabuto.github.io`.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select `main` and `/ (root)`, then **Save**.
5. Visit `https://elkanahnyabuto.github.io/` after deployment.

No build system or external JavaScript dependencies are required.
